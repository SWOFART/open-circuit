## Native Windows desktop walkthrough

**Platform and build.** Windows 11 Pro 10.0.26100, one monitor in use. The executable was built on 2026-11-20 at 00:20 with `tauri build --no-bundle` from the candidate (`13a7981`, frontend embedded, no dev server). The agent controlled the native window with the computer-use plugin after the user granted access. The Engine, the bridge and the numbers were the real ones. The Example divider circuit (5 V, 100 mΩ, 2 × 1 kΩ) was the document.

| Check                                 | Observed result                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Start                                 | The Parts drawer is open and floating at the left edge of the canvas, with the categories Sources, Passive, Protection, Switching and control, Measurement and so on, and a symbol preview next to every one of the 22 parts, the AC and three-phase sources included (none is a placeholder or dimmed, because every part has a symbol). After an earlier session the **Recent** group shows the parts chosen then: the preferences survived a restart. |
| Keyboard only: `/`, search, place     | `/` (typed as the character) opens the drawer with the search focused. | Keyboard only: Enter opens the editor | With a part selected on the canvas, Enter opens the editor next to it with the first field focused. | Load torque, live                     | In the motor's editor, Tab reached **M1 load torque**; `0.05` was committed with Enter and became `50 mN·m` in both the editor and the Inspector. | Double-click a part                   | A double-click on `R2` opens its editor next to it with the field focused. | Drag from the drawer                  | Dragging Switch from the drawer to an empty place on the canvas placed `S2` at the drop point, selected it and closed the floating drawer; the Select tool stayed active.                                                                                                                                                                                                                                                                                |

A double-click on the left terminal line, away from the lever, opened the editor of `S2`.                                                            |
