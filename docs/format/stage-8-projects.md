# Stage 8 project and assignment compatibility

Issue #130 implements the storage/validation portion of the
[DC rail contract](../contracts/stage-8-supply-rails.md). Rail net assembly is
#131 and canvas authoring is #133–#134. The schema-only layer rejects a
rail-bearing compile with `InvalidGeometry` rather than calculating a circuit
that ignores the stored rails; #131 replaces that transitional guard.

## Project inputs

`Schematic` is now v2 with a required `rails` array. Rust owns `RailSpec`, its
generated TypeScript definition and all electrical validation. A rail stores
only `id`, `name`, `start`, `end`. The contract gives the exact JSON shape and
name/extent rules; no derived node, computed value, state or history is saved.

`decode_project_json` probes the version and then decodes the original bytes
into an exact v1 or v2 shape. This retains duplicate-field checks. The frozen
v1 shape cannot contain `rails`, even an empty array. V1 is normalized purely
to v2 with empty rails, preserving every other drawn input. Unsupported or
malformed versions are rejected. Saving a project always writes v2, which an
older reader rejects instead of dropping an unknown conductor field.

New/Example use normalized v2 values. Loading v1 leaves its file untouched;
the UI's clean baseline is the normalized document, so migration alone does
not mark it dirty. An explicit save performs the existing atomic replacement.
Read/write failure still leaves the current document/path/history intact.

Names are exact case-sensitive ASCII labels, not nonlocal net aliases.
Validation rejects invalid names/lengths, geometry, cross-kind ID collisions,
duplicate names and more than 256 rails. Length uses i64 subtraction. A checked
rail-contact budget covers ordinary segments, resolved pins and markers
without iterating over grid coordinates; the full pin budget is checked at
compile's geometry boundary. A pinless rail is structurally saveable; topology
diagnostics are a separate concern.

## Assignment files versus live DTOs

`.ocassignment` remains version 1 with exact legacy schematic-v1 embedding.
`decode_assignment_json` / `validate_assignment_value` read that file shape
and return the current normalized DTO. The live `validate_assignment` Tauri
command calls Engine `validate_assignment_draft_value`; it accepts normalized
schematic-v2 DTOs with empty rails. Typed `validate_assignment` uses the same
current-shape path. This keeps file parsing separate from live request parsing
without a second TypeScript migration implementation.

`encode_assignment_json` validates the live DTO and explicitly exports only
rail-free schematics to frozen embedded v1. It refuses nonempty rails rather
than omitting them. Outer assignment version, byte limits, field-error ordering,
criteria/fault semantics and component-ID restrictions remain intact.

The public check evaluator guards both starting/student inputs. Nonempty rails
produce `UnsupportedAssignmentRails`, a failed outcome and no run-dependent
measurements. More than 256 rails produces `RailLimitExceeded` first with no
individual references. Static component-count/locked criteria retain their
existing meanings. These are rejection guards, not new rail fault/check kinds.

## Fixtures and verification

Current compile/check/drawing fixtures are normalized to v2 by metadata-only
edits. The original v1 divider remains at
[`stage-8-legacy-divider.ocircuit`](../../tests/golden/stage-8-legacy-divider.ocircuit).
All `.ocassignment` fixtures stay legacy v1; separate `.assignment.json` fixtures
pin the corresponding live DTOs and are compared with real Rust decoding.
The independent #129 wire snapshots intentionally stay v1 and exercise migration.

Run `cargo test -p open-circuit-engine --test stage_8_schema` for strict shapes,
legacy round-trip, numeric/geometry/name limits, cross-kind IDs, work bounds,
assignment conversions, direct-call guards and the temporary compile refusal.
Existing real-Engine physics and bridge recordings are regenerated by their
ordinary tests; numerical expectations/tolerances are unchanged.
